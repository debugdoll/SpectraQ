# SpectraQ
This project is about Adaptive Smart Lighting System . LED lighting systems degrade silently over time ,  lumen output drops, phosphor layers deteriorate, and the emitted colour temperature shifts away from its rated value. None of these changes are detectable through conventional electrical monitoring, meaning fixtures in classrooms, hospitals, museums, and industrial workspaces continue to operate with uncorrected, inaccurate lighting that demonstrably harms human productivity and wellbeing. SpectraQ addresses this gap by implementing a fully self-contained, closed-loop optical correction system built on the ESP8266 microcontroller and the TCS34725 RGB colour sensor. The system continuously measures the actual Correlated Colour Temperature (CCT) and illuminance produced by Warm and Cool white LED Strips, compares these readings against a user-defined target, and automatically adjusts the PWM duty cycles of warm and cool LED channels to maintain accurate output. A lightweight HTTP dashboard served directly from the ESP8266 provides real-time monitoring with no dependency on cloud platforms or external apps. Additionally, the system tracks PWM compensation trends over time to detect and flag LED aging  enabling predictive maintenance with no additional hardware cost. SpectraQ delivers affordable, verified, and intelligent lighting correction applicable to any precision-sensitive environment.
